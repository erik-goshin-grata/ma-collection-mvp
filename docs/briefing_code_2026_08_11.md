### 1. Stage 4b writes no observations

`stages/funding_hc_extract.py` does not import `write_staging_observations_for_extraction`. Only
`stages/high_confidence_extract.py` and `stages/low_confidence_extract.py` do. There is no
`FUNDING_HC_EXTRACT` value among the `observation_source_stage` strings found in the codebase
(`DT_CLASSIFY`, `HC_EXTRACT`, `LC_EXTRACT`, `AGREEMENT_EXTRACT`, `BACKFILL`).

**If true:** switching `AGGREGATION_READ_SOURCE=observation` nulls every funding-path field, not
merely the ones missing from `HC_FIELDS`. Larger than what `e66c88c` fixed.

Note `decisions.md` — "Guarded Observation-Backed Stage 9 Read Path" — scoped the observation
loader to four stages, and that decision **predates `003_funding_path.sql`**. So this may be
unimplemented scope rather than a regression. Worth distinguishing, because it changes whether the
fix is a bug fix or a scope extension requiring its own decision.

### 2. Seven `_FIELDS` entries have no observation-path source

Present in `_FIELDS` (`stages/aggregate.py`), absent from `STAGE3_FIELDS`, `HC_FIELDS` and

`acquirer_type_v2`, `announced_date_precision`, `closed_date_precision`, `rumor_date`,
`target_revenue_period_type_v2`, `target_ebitda_period_type_v2`, `financials_disclosure_status`

Plus the funding-path fields, which are covered by claim 1: `round_label`, `pre_money_valuation`,
`post_money_valuation`, `valuation_currency`, `facility_size`, `total_raised_to_date`,
`is_extension_round`, `is_down_round`, `is_bridge_round`, `use_of_proceeds`, `has_board_seat`,
`board_seat_notes`.

Some may be legitimately exclusive to the staging path. Per the parity spec, those should be

**If true:** a €50M round stores as `round_size = 50000000` with no currency. That matters beyond

Check this against `decisions.md` — "deal_value_currency: single currency tag on derived values" —
